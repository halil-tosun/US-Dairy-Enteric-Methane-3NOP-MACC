# Replication Guide

This guide walks through reproducing every table and figure in the
accompanying manuscript, step by step.

## 1. Set Up the Environment

**Option A -- Conda (recommended)**

```bash
conda env create -f environment.yml
conda activate dairy-macc-repro
```

**Option B -- pip**

```bash
python -m venv .venv
source .venv/bin/activate        # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Run the Full Pipeline

```bash
cd code
python run_all.py
```

You should see console output for sixteen steps, each printing the
table (or figure) it produces, followed by a total runtime
(approximately 10-15 seconds on a standard laptop).

## 3. Verify the Outputs

After running, check that the following files exist:

```

```

Note: the manuscript's Table 2 (external benchmark comparison) is
**not** regenerated by this pipeline -- it draws on a companion
analysis's own results, reported directly in the manuscript rather than
computed by this repository. See `docs/DATA_DESCRIPTION.md`, "External
Validation Benchmark Data."

## 4. Cross-Check Against the Manuscript

Open each CSV in `output/` and compare its values against the
corresponding table in the manuscript. Values should match exactly (to
the rounding shown); see `docs/REPRODUCIBILITY_CHECKLIST.md`,
"Internal Consistency Checks." If you find any discrepancy, please open
an issue in this repository, including your Python and package
versions.

## 5. Regenerate a Single Table or Figure

Each numbered script can, in principle, be run independently once the
environment is set up and the earlier stages of the pipeline it depends
on have been run at least once (most scripts read a `data/processed/`
or `output/` file produced by an earlier script -- see
`docs/CODEBOOK.md` for the full dependency structure). For example:

```bash
cd code
python 09_lever_a_marginal_curve.py
```

reproduces only Table 6 (Lever A's marginal cost curve), assuming
`02_lever_a_optimization.py` has already been run.

## 6. Understanding the Model

Before reusing or extending this package, read `docs/CODEBOOK.md` in
full, particularly:

- **"Why a Separate Marginal-Curve Script?"** -- explains why Lever A
  is represented by both a two-point comparison (Table 4, Figure 3) and
  a six-point marginal cost curve (Table 6), and why this distinction
  matters if you extend the analysis.
- **"A Corrected Modeling Choice (Lever C)"** -- explains why Lever C's
  milk-revenue-loss calculation uses the butterfat component price
  rather than the all-milk price, and documents a real correction made
  to this calculation during manuscript preparation.
- **"Monte Carlo Uncertainty Propagation"** -- explains the
  distributional choices for each uncertain parameter, and why the
  Kebreab et al. (2022) dose coefficient is deliberately excluded from
  the tornado sensitivity analysis (Figure 5).

Also read `docs/DATA_DESCRIPTION.md` for the provenance of every
constant and price figure, and note explicitly that **carbon prices,
lever-effect coefficients, and adoption rates are illustrative
scenario inputs, not survey-derived or region-specific estimates** --
see the Limitations discussion in the accompanying manuscript before
using any result for an operation- or region-specific decision.

## 7. Adapting This Package

This package was designed to be extended:

- **Different milk price or carbon price scenarios**: edit the
  corresponding constants at the top of `code/_paths.py`
  (`MILK_PRICE_100KG`, `CARBON_PRICE_LOW_USD_PER_TON`,
  `CARBON_PRICE_MID_USD_PER_TON`, `CARBON_PRICE_HIGH_RANGE_USD_PER_TON`).
- **Different animal (BW, milk yield, composition)**: edit `BW`,
  `MILK`, `FAT`, `PROT_MILK` in `code/_paths.py`. Because these
  constants are imported by every downstream script, a single edit
  propagates through the full pipeline -- no per-script changes are
  required.
- **Different ingredient prices or composition**: edit
  `data/processed/ingredient_library.csv` directly.
- **A different lever-effect coefficient or literature source**: each
  lever's coefficient(s) are isolated in a clearly labeled block in
  `code/_paths.py` (e.g., `# ---- Lever D: Replacement rate reduction
  ----`), each with its own inline citation; replace the coefficient
  and update the citation comment together.
- **More or fewer Monte Carlo iterations**: edit `MC_ITERATIONS` in
  `code/_paths.py`. `MC_SEED` controls reproducibility of the random
  draws; keep it fixed for exact reproducibility, or vary it to confirm
  that results are not an artifact of the particular random seed used.

## 8. Troubleshooting

- **`ModuleNotFoundError`**: confirm the environment from Step 1 is
  activated before running `run_all.py`.
- **`FileNotFoundError` for an `output/` or `data/processed/` file**:
  a script was run out of dependency order. Run `python run_all.py`
  from a clean state rather than an individual script, or consult
  `docs/CODEBOOK.md` for each script's dependencies.
- **Monte Carlo results differ slightly from the manuscript**: this
  should not occur given the fixed seed (`MC_SEED = 42`) and pinned
  package versions in `requirements.txt`; if it does, first confirm
  your NumPy version matches exactly, since NumPy's random number
  generator implementation has occasionally changed its internal
  algorithm across major versions even for a fixed seed.
- **Figures look different from the manuscript**: confirm your
  matplotlib version matches `requirements.txt`; minor rendering
  differences across matplotlib versions do not affect the underlying
  data, only cosmetic details (marker size, font rendering).
