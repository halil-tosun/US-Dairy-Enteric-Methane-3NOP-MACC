## Known, Documented Analytical Corrections

One substantive analytical correction was made to this study's Lever C
(rumen-available fat supplementation) economics during manuscript
preparation, prior to this package's release, and is disclosed here in
full for transparency:

**Lever C milk-revenue-loss calculation.** The source meta-analysis for
this lever's production penalty (de Ondarza et al., 2024) reports
reductions in milk fat percentage (-7.8%) and milk fat *yield*, kg/d
(-6.0%) -- both pertaining to milk fat, not overall milk yield, which
the source does not report as significantly affected. An earlier
internal version of this analysis had applied the 6.0% figure to
overall milk yield via the all-milk price, which substantially
overstated this lever's revenue-loss component ($390.79/cow/yr under
the earlier, incorrect calculation vs. $111.02/cow/yr under the
corrected calculation implemented in this package, which instead values
the milk-fat-yield reduction directly via the butterfat component
price). This was identified via independent cross-checking of this
study's source attribution against the source meta-analysis's own
reported abstract language, and corrected before this package's
release. See `docs/CODEBOOK.md`, "A Corrected Modeling Choice," and the
manuscript's Materials and Methods (Lever C) for the full account. The
corrected calculation is the only version implemented in this package;
no vestigial code path for the earlier, incorrect calculation remains.

No other discrepancies, corrections, or known numerical differences
between this package and the manuscript were identified.
